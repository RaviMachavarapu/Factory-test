severity: medium
cite: [RUSTSEC-2024-0429, GHSA-wrw7-89jp-8q8g, CWE-758]
cvss_vector: CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:N/VI:L/VA:N/SC:N/SI:N/SA:N
affects: [src-tauri/Cargo.lock:1283]

`glib` 0.18.5 (CVSS v4.0 6.9, the vector GHSA-wrw7-89jp-8q8g publishes) is
unsound (RUSTSEC-2024-0429, aliased GHSA-wrw7-89jp-8q8g): the `Iterator` and
`DoubleEndedIterator` impls for `glib::VariantStrIter` can trigger undefined
behavior. The advisory assigns no CWE; this review maps it to CWE-758,
Reliance on Undefined, Unspecified, or Implementation-Defined Behavior. It reaches this lockfile only via the gtk-rs GTK3
bindings that tauri's `wry` backend uses for its Linux `webkit2gtk` build.
This pack's macOS target (arm64, Xcode 27) never compiles that dependency,
so the unsound API is unreachable on any instance built from this skeleton.
Remediation: tracked upstream in tauri's own dependency graph; re-enumerate
at the next tauri pin bump. Re-enumerated on 2026-10-04 (tauri 2.12.1): glib
0.18.5 is still locked through the same Linux-only chain.

| Metric | Value | Why |
|---|---|---|
| Attack Vector | Network (AV:N) | GHSA-wrw7-89jp-8q8g publishes AV:N; reachability is bounded structurally (see above), not by this metric |
| Attack Complexity | Low (AC:L) | no special conditions once the unsound API is called |
| Attack Requirements | None (AT:N) | the advisory's own vector states none |
| Privileges Required | None (PR:N) | the caller needs no elevated access to trigger undefined behavior |
| User Interaction | None (UI:N) | no user action is needed once the code path runs |
| Vulnerable system C/I/A | None/Low/None | undefined behavior can corrupt iterator state (VI:L); confidentiality and availability are not published as impacted |

The `unic-char-range`, `unic-common`, `unic-char-property`, `unic-ucd-ident`
and `unic-ucd-version` crates (all 0.9.0) are unmaintained (no known
vulnerability — CWE-1104). All five reach this lockfile transitively via
`urlpattern`, which `tauri-utils` uses for custom-protocol parsing.
Remediation: replacing the `unic-*` family is upstream tauri's call; tracked
for the next tauri pin bump.

Fixed on 2026-10-04, no longer reachable: the pin bump's lock locks
`tauri-utils` 2.10.1 with `urlpattern` 0.6.0, which no longer depends on the
`unic-*` family; no `unic-*` crate is locked, and neither cargo-audit 0.22.2
nor osv-scanner 2.6.0 reports any of the five advisories. The `affects:` lines
above are the 2026-10-02 lock's (sha256 5871b662…), kept as the record of
where the finding stood; the disposition marks SEC-003 `fixed`.

Informational: no known vulnerability, so no impact is scored (`art-threat-driven-security`'s
informational row); low is the floor a finding takes.
