**A waiver was bound to a head, not a base: fixed.** Deferred at 3.2.0.
PR #65 (Tasks 1.1–1.2, plan R4) removed the cause. `WAIVER_RE` (`:87`)
accepts `sha:<head> base:<base>`. A bound waiver is judged by the marker's
merge-base rule and refused as `waiver-base-mismatch` after a retarget that
changes the diff (`:1230-1235`). A legacy waiver (no `base:`) stands only

reduces merged PRs through the same `pr_attestation`. `run-verifier.sh` and
the classifier's hints print the bound form. What stays is the timeline
read itself, a platform property the threat model records with no expiry
(Residuals, below). Score 5.9.
